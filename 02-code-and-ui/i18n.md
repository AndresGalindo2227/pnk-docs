# Texts and Internationalization (i18n)

V1 ships in **Spanish (Colombia, `es-CO`)** only — PANENKA players are in Neiva. Even with one
language, **all user-facing text is centralized**, so wording is reviewed in one place and a second
language can be added later without touching pages.

## Where texts live

| File | Content |
|------|---------|
| `src/app/core/i18n/texts.es.ts` | Typed catalog of every user-facing string, grouped by feature |
| `src/app/core/i18n/error-messages.es.ts` | Map from API error `code` to user message and action |
| `src/app/core/i18n/text.pipe.ts` | `{{ 'bookings.confirm.title' \| text }}` pipe for templates |

```ts
// texts.es.ts — keys are namespaced by feature; values are Spanish.
export const TEXTS_ES = {
  bookings: {
    confirm: { title: 'Confirmar reserva', button: 'Reservar' },
    slot: { free: 'Libre', taken: 'Ocupado' },
  },
  common: { retry: 'Reintentar', offline: 'Sin conexión. Mostrando datos guardados.' },
} as const;
```

```ts
// error-messages.es.ts — the API code decides the message (see 03-api-and-data/README.md).
export const ERROR_MESSAGES_ES: Record<string, string> = {
  SLOT_ALREADY_TAKEN: 'Alguien reservó esa hora hace un momento. Elige otra.',
  CANCELLATION_WINDOW_CLOSED: 'Solo puedes cancelar hasta 3 horas antes del partido.',
  INVALID_CREDENTIALS: 'Correo o contraseña incorrectos.',
  NETWORK: 'No hay conexión. Revisa tu internet e inténtalo de nuevo.',
  UNKNOWN: 'Algo salió mal. Inténtalo de nuevo.',
};
```

## Rules

- **No hardcoded user-facing strings** in templates or TypeScript. Code, comments and keys are
  English; values are Spanish.
- Keys are namespaced by feature: `bookings.confirm.button`, `auth.login.error`.
- Money is formatted with Angular `CurrencyPipe` / `Intl.NumberFormat('es-CO', { currency: 'COP',
  maximumFractionDigits: 0 })` → `$ 70.000`. Never concatenate `'$' + value`.
- Dates and times use `DatePipe` with `LOCALE_ID = 'es-CO'` and the venue time zone
  (`America/Bogota`, from `GET /config`) → `jueves 5 de noviembre, 7:00 p. m.`.
- Plurals use Angular ICU expressions (`1 hora` / `2 horas`), not string concatenation.
- Layout uses logical properties (`start` / `end`), ready for RTL even if not required in V1.

## Checklist

- [ ] No literal user-facing strings in code (`grep` for quotes in templates during review).
- [ ] Prices in COP without decimals; dates in `es-CO` and `America/Bogota`.
- [ ] Every API error code used by the screen has a message in `error-messages.es.ts`.
